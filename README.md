## Hi, I'm Renat 👋

**Senior Platform & DevOps Engineer.** I design, build and operate internal platforms that let product teams ship quickly without trading away reliability, security or cost control.

Most of my work sits where infrastructure meets developer experience. On one side are multi-account cloud foundations and Kubernetes fleets running in regulated, compliance-heavy environments. On the other are the golden paths, automation and self-service tooling that let hundreds of engineers use that infrastructure without having to think about it.

### What I do

- 🏗️ **Platform engineering:** internal developer platforms, golden paths and self-service scaffolding that give teams a paved road from idea to production
- ☸️ **Kubernetes at scale:** designing and running fleets of clusters, with node autoscaling, upgrades, multi-tenancy, service mesh and workload hardening
- 🔁 **GitOps and delivery:** declarative, multi-cluster, multi-environment delivery with CI/CD pipelines that have security built in
- 🧱 **Infrastructure as Code:** reusable, versioned infrastructure for multi-account cloud setups
- 🔐 **Security and compliance:** supply-chain security (scanning, SBOMs, provenance), secrets management, least-privilege identity and policy as code
- 💸 **Reliability and cost:** right-sizing, autoscaling strategy, ARM/Graviton adoption and observability that surfaces problems before users notice them

### How I work

- **Paved roads over gates.** The secure, compliant path should also be the easiest one.
- **Everything declarative.** If it isn't in Git and reconciled, it doesn't exist.
- **Boring technology, operated well.** I prefer proven tools that are deeply understood over the newest ones.
- **Write it down.** I document decisions as ADRs with their trade-offs, so the next engineer knows the *why* as well as the *what*.
